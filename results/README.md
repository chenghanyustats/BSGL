# Result Files

This directory contains curated result files rather than every exploratory output.

- `simulation/`: full 10-replicate simulation summaries, SCP summaries, and the retained BSGL hyperparameter sensitivity check.
- `real_data/`: MODIS EVI four-method prediction summaries and BSGL/GSVC SCP summaries, including the ten-variable SCP table and map data.
- `interaction/`: simulation and MODIS interaction validation summaries.
- `abrupt_boundary/`: abrupt-boundary simulation summaries and SCP values.
